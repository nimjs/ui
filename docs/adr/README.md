# Architecture decisions

Use a short ADR only for a durable cross-package decision whose rationale would be lost in a pull request. Current behavior and invariants remain in [architecture](../architecture.md). Do not reconstruct unknown history.

Suggested format:

```md
# ADR NNNN: Title

Status: Proposed | Accepted | Superseded
Date: YYYY-MM-DD

## Context

## Decision

## Consequences

## Alternatives considered
```

Link an accepted ADR from the relevant architecture section and update it when the contract changes.
